# Глоссарий: русский — English — 简体中文

Единая терминология интерфейса zaprett для Windows (ARCHITECTURE-WIN §12.2). Переводы в
`src/Zaprett.Ui/Core/Strings/zh-CN.json` пользуются только этими терминами; новый текст сверяется с
таблицей, а не переводится заново. Набор сверен 2026-09-23 с ядром (`src/Zaprett.Core/Text/Strings.cs`: 策略, 列表, 订阅,
引擎, 绕过, 自动选择, 监控, 看门狗, 预设, 任务, 仓库), CLI (`src/Zaprett.Cli/Strings/zh-CN.json`) и установщиком
(`installer/Localization/zh-CN.wxl`) — расхождений нет. Тесты `LocalizationTests` проверяют совпадение ключей и подстановок
`{0}` во всех трёх языках и отсутствие ASCII-кавычек в китайских строках.

## Правила китайского текста

- Пунктуация полноширинная: `，。：；？！（）`, кавычки `“…”`. Перечисления — через `、`
  (`L.List`, ключ `Fmt.ListSep`), группы — через `；` (`Fmt.GroupSep`).
- Латинские имена, домены, команды и числа остаются как есть и отделяются пробелом от иероглифов:
  `zaprett 服务`, `DNS 劫持`, `IP 网段`.
- Обращение нейтрально-вежливое (`您` — только там, где без него фраза звучит грубо), без сленга.
- Шрифт: Segoe UI Variable → запасной Microsoft YaHei UI (`Styles/Theme.xaml`).

## Тексты из данных и встроенные тексты WinUI

- Тексты из данных продукта (`presets.json`, манифесты списков и стратегий: название, описание,
  примечание) выбирает одна функция `L.Pick`: ru — исходное поле; en — `*_en`, иначе исходное;
  zh-CN — `*_zh`, иначе `*_en`, иначе исходное. Пустая строка считается отсутствием перевода.
- Встроенные тексты элементов WinUI (подписи переключателей, контекстные меню полей ввода) в
  неупакованном приложении берут язык из MUI-списка процесса. Его задаёт
  `Platform/ControlsLanguage.cs` (`SetProcessPreferredUILanguages` и `SetThreadPreferredUILanguages`)
  до `Application.Start`. Проверено 2026-09-23 на русской Windows: без явной подписи переключатель
  показал «On» в английском интерфейсе и «开» в китайском вместо «Вкл.».
  `ApplicationLanguages.PrimaryLanguageOverride` для этого не годится: версия `Windows.*` без
  идентичности пакета бросает исключение, а версия `Microsoft.*` и `CultureInfo` ничего не меняют.
- При переключении языка без перезапуска MUI-список обновляется, но WinUI мог уже загрузить свои
  ресурсы, поэтому подписи переключателей всё равно заданы явно (`Common.On` / `Common.Off`).
