# zaprett для OpenWrt

[English version / Описание на английском →](README.en.md)

Обход замедлений и блокировок по DPI на роутере с OpenWrt: порт Android-менеджера
[zaprett](https://github.com/CherretGit/zaprett-app) на движке
[nfqws](https://github.com/bol-van/zapret) с веб-интерфейсом LuCI на русском языке.

Одно устройство настраивается один раз — обход работает для всех домашних устройств, без VPN и прокси
на каждом телефоне. Меняются только первые пакеты соединений с выбранными сайтами, остальной трафик идёт как
обычно: без посредников, без потери скорости, без перенаправления трафика куда-либо.

![Веб-интерфейс zaprett: состояние службы и быстрая настройка](docs/screenshots/01-overview.png)

**С чего начать:** [установка](docs/INSTALL.md) → [руководство по настройке и возможностям](docs/GUIDE.md).

## Windows-приложение

Нет роутера с OpenWrt или нужен обход только на одном компьютере? **zaprett для Windows 0.1.1** делает то же самое на
ПК с Windows 10 (2004 и новее, включая LTSC 2021) и Windows 11 x64: мастер первой настройки, проверка сайтов, автоподбор
стратегии без остановки обхода, монитор, диагностика, свои списки и подписки. Один установщик MSI — всё нужное
(среда .NET, драйвер WinDivert, движки zapret и zapret2) уже внутри, интерфейс на русском, английском и китайском.

## Новое в версии 1.1

- **Монитор доступности** проверяет сайты по расписанию и при устойчивой деградации может сам подобрать стратегию;
  **сторож** поднимает движок и правила, если они пропали.
- **Диагностика «чем блокирует провайдер»**: подмена DNS, блокировка по IP, обрыв по имени сайта, замедление,
  страница-заглушка — и что поможет; шифрованный DNS одной кнопкой.
- **Собственные списки проекта** для YouTube, Discord, Telegram, RuTracker, Roblox, Signal и сайтов за Cloudflare
  с вариантами (основной, расширенный, IP-сети, голос Discord).
- **Автоподбор без остановки обхода**: стратегии проверяет отдельный тестовый движок.
- Своя таблица ускорения, блокировка QUIC, игровой фильтр, 14 стратегий для движка zapret2.
- Названия и описания сервисов, списков и стратегий есть на английском и китайском (китайские используются
  Windows-приложением).
- **Исправление безопасности.** В 1.0.0 проверка опций пользовательских стратегий была неполной: опцию можно было
  записать так, что проверка её не узнавала. В 1.1.0 каждая опция перед проверкой приводится к полному имени по
  таблицам опций самого движка, неизвестные и неоднозначные опции отклоняются. **Всем, кто пользуется 1.0.0,
  рекомендуется обновиться.**

## Что умеет

**Веб-интерфейс на русском** (LuCI → Службы → zaprett), шесть страниц: обзор, стратегии, списки,
репозиторий, настройки, диагностика. Всё, что делает интерфейс, доступно и из командной строки.

**Быстрая настройка в один экран.** Отмечаете сервисы, которыми пользуетесь (YouTube, Discord, Telegram,
RuTracker, сайты за Cloudflare, «прочие заблокированные») — включаются готовые списки, списки IP-сетей и
обязательные исключения (госуслуги, банки, Яндекс, VK, маркетплейсы), режим «белый список». Сервисы, которым
обход **не поможет** (WhatsApp, Instagram/Facebook, X, ChatGPT/Claude, Spotify), показаны с честной причиной,
и включить их нельзя. Интерфейс знает объём памяти роутера и предупреждает, если выбранное для него тяжело.

**Автоподбор стратегии.** У разных провайдеров работают разные стратегии — продукт перебирает их сам:
сначала проверяет цели без обхода, потом с каждой стратегией, ранжирует и предлагает лучшую. 64 готовые
стратегии из репозитория zaprett и 14 собственных стратегий для движка zapret2 (включая оркестратор, который сам
переключает приёмы для сайта при сбоях); можно проверить рекомендованные за несколько минут или все установленные.
**Во время подбора обход для ваших устройств продолжает работать**: стратегии проверяет отдельный тестовый движок.

**Видно, работает ли обход сейчас.** Кнопка «Проверить сейчас» открывает адреса включённых сервисов через
работающий обход и показывает, что открылось. **Монитор** по расписанию делает то же сам, хранит историю проверок
и при устойчивой деградации может сам запустить автоподбор и применить стратегию, только если она лучше текущей.
**Сторож** каждые 5 минут поднимает движок и правила, если они пропали.

**Чем блокирует провайдер.** Диагностика отличает подмену DNS, блокировку по IP, обрыв по имени сайта, замедление
и страницу-заглушку и говорит, что поможет: стратегия, шифрованный DNS или только VPN. Шифрованный DNS
(https-dns-proxy) включается одной кнопкой.

**Собственные списки проекта.** Для YouTube, Discord, Telegram, RuTracker, Roblox, Signal и сайтов за Cloudflare —
по несколько вариантов (основной, расширенный, IP-сети, голос Discord). Их собирает генератор проекта из
первоисточников: документация сервисов, сертификаты, реальные сессии браузера, код клиентов, анонсы автономных
систем; каждая запись проверена и объяснена в журнале сборки ([docs/LISTS.md](docs/LISTS.md)).

**Быстро и на слабом железе.** Своя таблица ускорения (flow offloading) вместо отключения ускорения для всего
роутера, блокировка QUIC одной галочкой, игровой фильтр для игр по UDP, ограничения размера загрузок и памяти.

**Списки под контролем.** Встроенные списки, свои домены и IP-сети,
исключения (действуют в обоих режимах), подписки на внешние списки по https-ссылке с автообновлением
(Re:filter, antifilter.download, официальные диапазоны Cloudflare) — с защитой от «пустых» файлов, пределом
16 МиБ на загрузку и записью на флеш только при реальном изменении.

**Репозиторий zaprett** прямо из интерфейса: каталог стратегий и списков, проверка sha256, зависимости,
установка/обновление/удаление фоновыми задачами с прогрессом и отменой.

**Фильтр по устройствам LAN** (аналог списка приложений в Android-версии): обход для всех, только для
перечисленных или для всех, кроме перечисленных — по IP, подсети или MAC.

**Аккуратность к системе.** Правила живут в отдельной таблице nftables `inet zaprett` и не переписывают
правила вашего межсетевого экрана; они восстанавливаются после `reload`, `restart` и полной остановки
firewall, а также после перезагрузки роутера. Движок работает не от root. Ускорение (flow offloading),
которое пропускает пакеты мимо межсетевого экрана, продукт либо заменяет своей таблицей ускорения, которая
пропускает первые пакеты соединения через обход, либо выключает на время работы, — и возвращает как было.

**Работает без доступа к GitHub**: всё нужное для старта — движок, 64 + 14 стратегий, собственные списки — лежит в пакете.

## Требования

- OpenWrt **24.10.x** (opkg) или **25.12.x** (apk), межсетевой экран fw4/nftables.
- Поддерживаемые архитектуры: x86_64, aarch64, arm (ARMv6 и новее), mips, mipsel и другие — 27 для 25.12 и 28
  для 24.10. **Не поддерживаются** ARMv4/v5 (`arm926ej-s`, `fa526`, `xscale`) и riscv64.
- Свободной оперативной памяти: от ~20 МБ со встроенными списками. Большие реестры заблокированных сайтов
  требуют роутера от 200 МБ ОЗУ — интерфейс предупредит.
- Свободной флеш-памяти: 2 МБ (пакеты 0,6–0,8 МБ плюс зависимости).
- Интернет на роутере при установке (нужны модули ядра `kmod-nft-queue` из официального репозитория).

## Установка

Скачайте бандл для своей версии OpenWrt и архитектуры из раздела
[Releases](../../releases), затем на роутере:

```sh
tar -xzf zaprett-1.1.0-r1-25.12-x86_64.tar.gz
cd zaprett-1.1.0-r1-25.12-x86_64
sh install.sh
```

Установщик сам проверит, что бандл подходит роутеру, добавит открытый ключ, подключит фид с проверкой подписи
и поставит пакеты. Подробно, включая установку без SSH и обновление прошивки, — [docs/INSTALL.md](docs/INSTALL.md).

Дальше: LuCI → **Службы → zaprett** → «Быстрая настройка» → отметить сервисы → «Применить и запустить».
Мастер включит списки, запустит обход и проверит, открываются ли сайты; если какой-то сервис не открылся,
он предложит «Подобрать рабочую стратегию» или сначала «Выяснить, чем блокирует провайдер».

Удаление: `sh install.sh --uninstall` (с `--purge` — вместе с настройками и списками).

## Из командной строки

```sh
zaprett status            # состояние, списки, предупреждения
zaprett start | stop | restart
zaprett check             # проверить настройки без запуска
zaprett test start --quick # автоподбор стратегии, zaprett test status — ход
zaprett list enable zaprett-telegram
zaprett sources update    # обновить подписки
zaprett diag              # быстрый отчёт; zaprett diag --full — полный
```

Полный справочник — [docs/BACKEND.md](docs/BACKEND.md) §6.

## Честно о возможностях

- Обход помогает против **анализа трафика (DPI)**: замедление YouTube, блокировка Discord и подобное.
- Он **не помогает**, если сервис заблокирован по IP-адресам (Instagram, Facebook, X), закрывает доступ сам
  (ChatGPT, Claude, Spotify) или блокировка сделана через DNS (домены WhatsApp исключены из НСДИ — нужен
  шифрованный DNS на роутере).
- **Стратегия по умолчанию может не работать у вашего провайдера.** Это нормально: запустите автоподбор.
- Проверено на стенде через реального провайдера: без обхода из 25 целей открывалась 1, с подобранной
  стратегией YouTube, Discord и RuTracker открываются полностью с клиента за роутером.
- Проверялось на x86-виртуальных машинах OpenWrt 25.12.5 и 24.10.8. На реальном железе (MIPS/ARM) пакеты
  собраны, но не протестированы. Совместная работа с VPN/прокси на том же роутере не проверялась.
  Полный список проверенного и непроверенного — [tests/RESULTS.md](tests/RESULTS.md).
