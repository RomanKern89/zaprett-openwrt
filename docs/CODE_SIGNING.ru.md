# Политика подписи кода (Code signing policy)

[English](CODE_SIGNING.md) | **Русский**

Это политика подписи кода для **zaprett для Windows** — Windows-части проекта
[zaprett-openwrt](https://github.com/RomanKern89/zaprett-openwrt).

Free code signing provided by [SignPath.io](https://about.signpath.io/), certificate by
[SignPath Foundation](https://signpath.org/).
(Бесплатная подпись кода — SignPath.io, сертификат — SignPath Foundation.)

> **Состояние.** Проект подал или собирается подать заявку на бесплатную подпись кода от SignPath Foundation. Пока не
> вышел первый подписанный выпуск, MSI на странице выпусков **не подписаны** Authenticode, и Windows SmartScreen может
> предупреждать при запуске. В описании каждого выпуска сказано, подписан ли он. Выпуски до `win-v0.1.4` включительно
> не подписаны.

## Что подписывается

Выпуск zaprett для Windows (`zaprett-<версия>-x64.msi`, тег `win-v<версия>`) подписывается за один проход:

1. сначала наши собственные файлы программы внутри MSI: `zaprett.exe`, `zaprett.dll`, `zaprett-svc.exe`,
   `zaprett-svc.dll`, `zaprett-ui.exe`, `zaprett-ui.dll`, `Zaprett.Core.dll`, `Zaprett.Ipc.dll`;
2. затем сам MSI.

В каждом подписанном файле указаны название продукта `zaprett for Windows` и версия выпуска. SignPath откажется
подписывать файл, у которого эти сведения не совпадают (см. `.signpath/artifact-configuration.xml` в репозитории).

## Что не подписывается

В установщике есть и файлы других проектов. Они поставляются ровно в том виде, в каком их публикуют авторы, и нашим
сертификатом **не** подписываются:

| Файлы | Проект | Примечание |
|-------|--------|------------|
| `engine\winws.exe`, `engine\cygwin1.dll` | [bol-van/zapret](https://github.com/bol-van/zapret) | закреплённый выпуск, при сборке сверяется SHA-256 |
| `engine2\winws2.exe`, `engine2\cygwin1.dll`, `engine2\lua\*` | [bol-van/zapret2](https://github.com/bol-van/zapret2) | закреплённый выпуск, при сборке сверяется SHA-256 |
| `WinDivert.dll`, `WinDivert64.sys` | [WinDivert](https://github.com/basil00/WinDivert) | драйвер `WinDivert64.sys` подписан его автором |
| среда .NET, Windows App SDK, прочие библиотеки | Microsoft и .NET Foundation | большинство из них подписаны самой Microsoft |

Точные версии и SHA-256 файлов движка закреплены в `windows/engine/engine.lock.json`.

Пакеты для OpenWrt — не программы для Windows, эта политика их не касается.

## Как собирается и подписывается выпуск

- MSI собирается из исходного кода этого репозитория в GitHub Actions на машинах GitHub
  (`.github/workflows/windows.yml`); сборку запускает тег `win-v<версия>`.
- Сборка отправляет неподписанный MSI в SignPath. Перед подписью SignPath проверяет, что файл получен именно этим
  запуском сборки этого репозитория.
- **Каждый запрос на подпись утверждается вручную** (роль «утверждающий», см. ниже). Без утверждения ничего не
  подписывается.
- Затем сборка проверяет подписи MSI и наших файлов внутри него, считает `SHA256SUMS` и манифест обновления
  `update.json` по подписанному MSI и публикует выпуск.

## Конфиденциальность

В zaprett для Windows **нет телеметрии, аналитики, отправки отчётов о сбоях и учётных записей**. Программа не
отправляет ни проекту, ни кому-либо ещё никаких сведений о вас, вашем компьютере или трафике. Настройки и журналы
остаются на компьютере (`C:\ProgramData\zaprett`).

Программа выполняет только те сетевые запросы, которые нужны для её функций. Каждый из них — обычное скачивание или
соединение, личных данных в них нет:

| Когда | Куда | По умолчанию |
|-------|------|--------------|
| Ежедневное обновление стратегий и списков, установленных из репозитория | индекс репозитория из настроек (по умолчанию `raw.githubusercontent.com`, репозиторий `CherretGit/zaprett-repo`) и перечисленные в нём файлы | **включено** по умолчанию; тот, кто устанавливает программу, видит этот переключатель на последнем шаге мастера и может выключить его там или позже в **Настройках**, группа **Обновления** (настройка `repo.autoupdate`) |
| Проверка новой версии программы | выпуски этого проекта на GitHub | включено, выключается в настройках; в версии 0.1.4 проверка в самой программе ещё не работает |
| Обновление подписок на списки | адреса подписок, которые вы включили | выключено: каждая подписка выключена, пока вы её не включите |
| Проверка сайтов, диагностика, автоподбор стратегии | сайты выбранных вами сервисов, а для сравнения ответов DNS — DNS-over-HTTPS-серверы `dns.google` и `cloudflare-dns.com` | только когда вы их запускаете |
| Контроль соединения, пока работает обход | сайты выбранных вами сервисов и несколько доменов из используемых списков | включено, пока включён обход; можно выключить |
| Шифрованный DNS (Windows 11) | `cloudflare-dns.com`, через DNS-клиент Windows | выключено, пока вы его не включите |

Как и при любом скачивании, сервер, к которому идёт запрос, видит ваш IP-адрес; для этих запросов действуют правила
конфиденциальности соответствующих служб (GitHub, Cloudflare, Google, поставщики списков).

Иными словами: программа не передаёт никаких сведений другим системам в сети, если об этом специально не попросил
пользователь либо тот, кто её устанавливает или управляет ею.

## Как проверить подписанный выпуск

1. Сверьте хэш: скачайте `SHA256SUMS` из того же выпуска и сравните, например в PowerShell:

   ```powershell
   (Get-FileHash .\zaprett-<версия>-x64.msi -Algorithm SHA256).Hash
   ```

2. Проверьте подпись MSI: правый щелчок по файлу, **Свойства**, **Цифровые подписи**. Подписант —
   **SignPath Foundation**. Или в PowerShell:

   ```powershell
   Get-AuthenticodeSignature .\zaprett-<версия>-x64.msi | Format-List Status, SignerCertificate, TimeStamperCertificate
   ```

   `Status` должен быть `Valid`.

3. После установки файлы программы в `C:\Program Files\zaprett` (`zaprett.exe`, `zaprett-svc.exe`, `zaprett-ui.exe` и
   их DLL) подписаны той же подписью.

Обновления из самой программы защищены дополнительно: манифест обновления `update.json` подписан собственным ключом
ed25519 проекта (`windows/tools/update-sign/keys/update-ed25519.pub`) и содержит SHA-256 MSI.
