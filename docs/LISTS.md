# Списки, стратегии и пресеты zaprett для OpenWrt

Этот документ объясняет, какие данные встроены в пакет `zaprett`, что включено сразу после установки, где обход
не поможет и как добавить свои сайты. Данные сняты **2026-09-17**. Технические источники фактов:
`research/03-lists.md` (листы и память), `research/01-zapret-core.md` §5 (стратегии), `docs/ARCHITECTURE.md` §3, §4, §9.

---

## 1. Что встроено в пакет

Всё встроенное лежит в `/usr/share/zaprett/bundle/` и работает без доступа к GitHub. Эти файлы не редактируются
(при обновлении пакета они заменяются новыми), но любой встроенный список можно выключить или дополнить своим.

### 1.1. Списки сайтов и IP-сетей

| Id | Название в интерфейсе | Что внутри | Записей | Откуда |
|---|---|---|---:|---|
| `zaprett-youtube` | YouTube | сайт, видео (`googlevideo.com`), превью, API | 13 | очищенный набор (см. ниже) |
| `zaprett-discord` | Discord | сайт, приложение, вложения, `discord.media` | 19 | очищенный набор |
| `zaprett-telegram` | Telegram | `telegram.org`, `t.me`, `telesco.pe` и др. | 17 | очищенный набор |
| `zaprett-rutracker` | RuTracker | `rutracker.org`, `.net`, `.ru`, `.cc`, `.wiki` | 5 | `list-rutracker` из CherretGit/zaprett-repo без изменений |
| `zaprett-telegram-ipset` | Telegram: IP-сети | сети серверов Telegram (15 104 адреса IPv4 и 4 сети IPv6) | 12 | официальный `core.telegram.org/resources/cidr.txt` + анонсы автономных систем Telegram по RIPEstat |
| `zaprett-exclude` | Исключения: сайты | госуслуги, банки, Яндекс, VK, маркетплейсы, игры и софт | 379 | Flowseal `list-exclude` + zaprett-repo `list-exclude-general` + remittor |
| `zaprett-exclude-ipset` | Исключения: локальные сети | частные сети, loopback, link-local, CGNAT, multicast | 11 | исключения bol-van/zapret + Flowseal |

**Как чистились списки YouTube, Discord и Telegram.** Домен попадал в набор, только если он есть минимум в двух
независимых источниках (CherretGit/zaprett-repo, Flowseal/zapret-discord-youtube, itdoginfo/allow-domains,
remittor/zapret-openwrt) и реально существует в DNS (проверка через два DoH-резолвера с контролями). Поддомены
удалены, если есть родительский домен: nfqws сам учитывает все поддомены. Что и почему отброшено — в
`research/03-lists.md` §6.1 и журнале `upstream/lists-refs/curated/BUILD_LOG.tsv`.

Почему не взяты готовые списки zaprett-repo: они устарели и содержат мусор. Например, в `list-general` 12
несуществующих узлов googlevideo, в `ipset-telegram` в 1 457 раз больше адресов, чем у Telegram на самом деле,
а `list-extended` занимает в памяти nfqws около 74 МиБ (`research/03-lists.md` §3).

Все встроенные листы вместе занимают в памяти nfqws меньше 0,1 МиБ.

### 1.2. Стратегии и фейки

- **64 стратегии nfqws** из CherretGit/zaprett-repo (коммит `09b30f0`, 2026-05-31) — байт в байт, sha256 каждой
  сверен с манифестом репозитория. Авторы по манифестам: Snowy-Fluffy — 39, flowseal (порты стратегий
  Flowseal/zapret-discord-youtube) — 15, sch-izo/dotFelixan — 5, по одной — zaprett-devs, roman5432990,
  Hellogames_., Adwhweu (ALT11), Danil7726.
- **6 фейковых пакетов** (`bin`): `quic_initial_www_google_com`, `tls_clienthello_www_google_com`,
  `tls_clienthello_4pda_to`, `tls_clienthello_max_ru`, `tls_clienthello_vk_com`, `tls_clienthello_sberbank_ru`.
  Их используют стратегии; все зависимости всех 64 стратегий есть в пакете.

Стратегии для nfqws2 в zaprett-repo пока нет, поэтому встроенных стратегий nfqws2 тоже нет.

## 2. Что включено по умолчанию

Сразу после установки служба **выключена** — её запускают на странице «Службы → zaprett → Обзор», там же есть
быстрая настройка по сервисам. Когда служба запущена с настройками по умолчанию:

| Что | Значение |
|---|---|
| Режим | `whitelist`: обход применяется только к сайтам из включённых списков (`blacklist` — ко всем, кроме исключений) |
| Списки сайтов | YouTube, Discord и ваш личный список (`user-hosts`, изначально пуст) |
| Исключения | «Исключения: сайты», «Исключения: локальные сети», ваши исключения |
| Стратегия | `strategy-general` (general из набора Flowseal) |
| Подписки из интернета | все выключены |

Telegram и RuTracker встроены, но не включены: их включают в мастере или на странице «Списки». Исключения
действуют в обоих режимах и проверяются раньше списков.

## 3. Где zaprett не поможет

zaprett обходит **DPI** — оборудование, которое узнаёт сайт по содержимому трафика (по имени сайта в
зашифрованном соединении) и замедляет или рвёт соединение. Против других способов блокировки он бессилен.

| Сервис | Как ограничен | Поможет ли zaprett | Что делать |
|---|---|---|---|
| YouTube | замедление по имени сайта (DPI) | **да** | включить список, при необходимости — автоподбор стратегии |
| Discord | блокировка РКН | **да** для сайта и чатов; голос — отдельное правило стратегии по портам UDP, официального списка портов нет | если нет голоса — другая стратегия |
| Telegram | ограничение звонков (с 2025-08) и медиа (с 2026-02) | **частично**: приложение ходит по IP, для него включается список IP-сетей; помогает ли против текущего замедления — **не проверено** | включить оба списка Telegram |
| RuTracker | давняя блокировка РКН | **частично**: помогает против DPI, но не против подмены DNS | при подмене DNS — шифрованный DNS (пакет `https-dns-proxy`) |
| Сайты за Cloudflare | с 2025-06 грузятся только первые 16 КБ | **не проверено**; подключаются официальные сети Cloudflare | выключить, если что-то сломалось |
| WhatsApp | домены исключены из НСДИ в 2026-02 — это блокировка DNS | **нет** | шифрованный DNS на роутере или VPN |
| Instagram, Facebook | блокировка по IP-адресам | **нет** | VPN или прокси |
| X (Twitter) | блокировка по IP-адресам | **нет** | VPN или прокси |
| ChatGPT, Claude | доступ закрывают сами сервисы: России нет в списке поддерживаемых стран | **нет** | VPN |
| Spotify | сам ушёл из России в 2022-04 | **нет** | VPN |

Эти сервисы показаны в мастере с честной пометкой, но мастер их не включает.

## 4. Подписки: лёгкий и полный уровни

Кроме встроенных списков, zaprett умеет загружать большие списки из интернета и обновлять их сам. По умолчанию
все подписки выключены.

| Подписка | Что это | Объём на 2026-09 | Память nfqws (замер, 64 бит) | Место на флеш | Уровень |
|---|---|---|---|---|---|
| `cloudflare_v4`, `cloudflare_v6` | официальные диапазоны Cloudflare (`cloudflare.com/ips-v4`, `/ips-v6`) | 15 + 7 сетей | меньше 10 КБ | меньше 1 КБ | лёгкий |
| `refilter_domains` | Re:filter `domains_all.lst` — заблокированные домены | 81 061 домен | 8,75 МиБ | 1,33 МБ | полный |
| `antifilter_allyouneed` | antifilter.download `allyouneed.lst` — заблокированные IP-сети | 16 753 сети | 1,28 МиБ | 0,26 МБ | полный |

- **Лёгкий уровень** подходит любому роутеру, в том числе с 64 МБ оперативной памяти.
- **Полный уровень** (пункт «Прочие заблокированные сайты» в мастере) — только для роутеров от 200 МБ памяти,
  лучше от 256 МБ. Вместе две подписки полного уровня занимают около 10 МиБ памяти и 1,6 МБ флеш-памяти.
  На 32-битных роутерах расход ожидается примерно в 0,6–0,7 раза меньше, но **это не проверено**.
- Мастер подсказывает уровень по объёму памяти роутера. Большие списки обновляются не чаще раза в 2–3 суток:
  частая перезапись изнашивает флеш-память.
- Многие сайты из больших списков заблокированы по IP или DNS — против них обход не сработает, даже если
  подписка включена.

**Не подключайте** списки на сотни тысяч записей: `list-extended` из zaprett-repo (около 74 МиБ памяти),
antifilter `domains.lst` (около 180 МиБ), bol-van/rulist `reestr_hostname_resolvable` (около 84 МиБ) — роутер
останется без памяти.

## 5. Как добавить свои сайты

**В веб-интерфейсе:** «Службы → zaprett → Списки».

- Вкладка «Домены» → редактор своих доменов (`user-hosts`): сайты, для которых нужен обход. Этот список включён
  по умолчанию, достаточно вписать домены и сохранить.
- Там же — свои исключения (`user-hosts-exclude`, тоже включён): сайты, которые обход трогать не должен.
- Вкладка «IP-сети» → свои IP-сети (`user-ipset`, его нужно включить переключателем) и свои исключения IP-сетей
  (`user-ipset-exclude`, включён).

**Правила записи** (так их понимает nfqws):

- один домен на строку, без `https://`, без пути и без пробелов: `example.com`;
- поддомены учитываются автоматически: `example.com` покрывает `www.example.com` и `cdn.example.com`;
- `^example.com` — только сам домен, без поддоменов;
- маски `*.example.com` **не работают** — пишите просто `example.com`;
- кириллические домены — только в punycode: `xn--e1afmkfd.com`, а не `пример.com`;
- комментарий — строка, которая начинается с `#`;
- IP-сети — по одной на строку: `203.0.113.0/24`, `2001:db8::/32` или отдельный адрес `203.0.113.7`;
- размер личного списка — до 1 МиБ.

**Через SSH:**

```sh
zaprett user set user-hosts < my-domains.txt      # заменить личный список доменов
zaprett user get user-hosts                       # посмотреть
zaprett list enable user-ipset                    # включить личный список IP-сетей
```

nfqws перечитывает изменённые списки сам. Если изменения не подхватились — перезапустите службу
(`zaprett restart` или кнопка на странице «Обзор»).

## 6. Стратегии: что выбрано и почему

### 6.1. Стратегия по умолчанию

`strategy-general` — стратегия general (файл `general.bat`) из набора Flowseal/zapret-discord-youtube для Windows;
из этого набора в zaprett-repo портированы 17 стратегий. Для HTTPS она отправляет фейковый пакет и перемешивает
части запроса (`fake,multidisorder`), для QUIC — фейковый пакет, для голоса Discord — отдельное правило по портам.

### 6.2. Быстрый автоподбор

Полный автоподбор проверяет все 64 стратегии и идёт долго. Быстрый проверяет 12 стратегий, отобранных так:

1. **Без ошибок.** Все зависимости найдены, плейсхолдеры разрешаются, опции и режимы есть в nfqws v72.13
   (проверяет генератор, см. §8).
2. **Не трогают чужой трафик.** Исключены стратегии, в которых есть правило на весь трафик порта независимо от
   списков: `strategy-alt5` (syndata для всего HTTPS) и `strategy-default` (весь UDP 50000–50100). На роутере
   такое правило затронуло бы все устройства сети и все сайты.
3. **Разные техники.** Какой приём сработает у конкретного провайдера, заранее не узнать. Поэтому стратегии
   в наборе различаются способом десинхронизации (фейк, разрезание, перемешивание, перекрытие) и способом
   «испортить» фейковый пакет, чтобы сервер его отбросил (md5sig, badseq, ts, autottl).
4. **Известность.** Основа — general и ALT-серия (основные стратегии репозитория Flowseal/zapret-discord-youtube)
   и специализированные discord-fix и youtubefix-alt из zaprett-repo. Статистики скачиваний нет, так что это выбор
   по известности наборов, а не по измеренной популярности.

| # | Стратегия | Техника для HTTPS (TCP 443) | Чем отличается от остальных |
|---:|---|---|---|
| 1 | `strategy-general` | фейк + перемешивание частей (`fake,multidisorder`), md5sig + badseq | стратегия по умолчанию |
| 2 | `strategy-alt` | фейк + разрезание с фейками (`fake,fakedsplit`), ts, фейк TLS google | порча фейка через ts |
| 3 | `strategy-alt2` | разрезание с перекрытием 652 байта (`multisplit`) | без фейковых пакетов |
| 4 | `strategy-alt3` | `fakedsplit`, badseq, autottl | TTL фейка вычисляется автоматически |
| 5 | `strategy-alt4` | `fake,multisplit`, md5sig, фейк TLS google | md5sig с разрезанием, без перемешивания |
| 6 | `strategy-alt8` | только фейк, badseq, фейк без модификаций | самый простой вариант с badseq |
| 7 | `strategy-alt11` | `fake,multisplit` с перекрытием 681/654, ts, фейк TLS max.ru | другой фейк (max.ru) |
| 8 | `strategy-fake-tls-auto-alt` | `fake,fakedsplit`, badseq, фейк со случайными полями и SNI google | фейк TLS генерируется на лету |
| 9 | `strategy-fake-tls-auto-alt3` | `fake,multisplit` с перекрытием 681, ts, фейк TLS на лету | генерируемый фейк + перекрытие |
| 10 | `strategy-simple-fake` | только фейк, ts, фейк TLS google | самый простой вариант с ts |
| 11 | `strategy-discord-fix` | `fake,split` (= `fakedsplit`), badseq, autottl; UDP 50000–65535 по IP-спискам | из набора под Discord |
| 12 | `strategy-youtubefix-alt` | `fake,split` (= `fakedsplit`), md5sig, autottl | из набора под YouTube |

### 6.3. Особенности стратегий, которые zaprett исправляет сам

Файлы стратегий в пакете не изменены. Перед запуском генератор аргументов приводит их в порядок:

| Особенность | Сколько стратегий | Что делает zaprett |
|---|---:|---|
| Устаревшие имена режимов `split`, `split2`, `disorder2` | 31 | заменяет на `fakedsplit`, `multisplit`, `multidisorder` — поведение nfqws то же |
| `--comment` со словами через пробел (все `strategy-shizapret-*`) | 5 | выбрасывает комментарий вместе со словами |
| Обратные слеши `\` в концах строк (`strategy-alt11`) | 1 | удаляет |
| Нет перевода строки в конце файла (`strategy-alt2-roblox`) | 1 | ни на что не влияет |

Что стоит знать при ручном выборе стратегии:

- `strategy-alt5` и `strategy-default` действуют на **весь** трафик своего порта, а не только на сайты из
  списков (см. §6.2).
- Все `strategy-shizapret-*` обрабатывают рукопожатие WireGuard на любом UDP-порту: если у вас на роутере или за
  ним работает WireGuard-VPN, эти стратегии будут добавлять фейковые пакеты в начало его соединений.
- 37 стратегий задают широкий диапазон UDP-портов (50000–65535, 49152–65535 или все порты). Правила nft ставят в
  очередь только первые пакеты соединения, но на слабом роутере такой диапазон заметнее нагружает процессор.
- `syndata` (7 стратегий) и `autottl` (53) требуют, чтобы в очередь nfqws попадали самый первый пакет соединения
  и первые ответы сервера. Правила nft zaprett по умолчанию так и настроены (первые 9 исходящих и 3 входящих
  пакета TCP); если уменьшить эти лимиты в расширенных настройках, такие стратегии могут перестать работать.

Полный машиночитаемый разбор — `tools/data/strategy_audit.json`.

## 7. Как автоподбор проверяет сервисы

Автоподбор скачивает контрольные адреса через каждую стратегию. Ответ считается успешным, если скачано не меньше
`min_bytes`. Ограничение «16 КБ» у Cloudflare и похожих хостингов даёт ровно такой симптом: начало ответа
приходит, дальше соединение зависает. Поэтому для больших ответов порог выбран выше 16 384 байт и заметно ниже
реального размера.

| Сервис | Адрес | `min_bytes` | Размер ответа, байт |
|---|---|---:|---|
| YouTube | `https://www.youtube.com/` | 131 072 | 928 951 / 929 117 / 932 426 |
| YouTube | `https://i.ytimg.com/vi/dQw4w9WgXcQ/hqdefault.jpg` | 17 000 | 21 011 ×3 |
| YouTube | `https://redirector.googlevideo.com/report_mapping?di=no` | 0 | 98 ×3 (важен сам ответ сервера) |
| Discord | `https://discord.com/` | 65 536 | 170 127 ×3 |
| Discord | `https://gateway.discord.gg/` | 0 | HTTP 404 ×3 (важен сам ответ сервера) |
| Telegram | `https://telegram.org/` | 17 000 | 19 919 / 19 919 / 19 918 |
| RuTracker | `https://rutracker.org/forum/index.php` | 32 768 | 96 334 ×3 |
| Сайты за Cloudflare | `https://speed.cloudflare.com/__down?bytes=102400` | 65 536 | 102 400 ×3 |

Размеры сняты 2026-09-17 с рабочей станции разработчика: `curl --http1.1 -A uclient-fetch`, по три запроса.
Это справочные размеры ответов, а не проверка доступности: шёл ли этот трафик через обход или VPN, не
проверялось. Для «Прочих заблокированных сайтов» отдельных адресов нет:
автоподбор берёт домены из самой подписки.

## 8. Для разработчиков: как пересобрать данные

```sh
PYTHONUTF8=1 python tools/data/build_bundle.py               # сборка, проверки, установка в пакет
PYTHONUTF8=1 python tools/data/build_bundle.py --check-only  # проверить то, что лежит в пакете
PYTHONUTF8=1 python tools/data/test_build_bundle.py          # положительные и отрицательные контроли
```

- Входы зафиксированы sha256: очищенные листы (`research/03-lists.md` §10), `index.json` zaprett-repo, каждая
  стратегия и фейк сверяются с манифестом репозитория. При любом расхождении сборка останавливается, пакет не
  меняется. Чтобы обновить данные, пересоберите листы по `research/03-lists.md` §10, проверьте изменения и
  обновите хэши в `build_bundle.py`.
- Сборка воспроизводима: повторный запуск даёт то же дерево (дайджест печатается в конце).
- Проверки: UTF-8 без BOM, LF (CR считается побайтно), без пробелов и масок в листах, валидные домены и CIDR,
  без дублей и перекрытий, включённые домены не перекрыты исключениями, уникальные id, совпадение sha256,
  разрешение зависимостей и плейсхолдеров (`${bin:…}` и т. п.), опции и режимы стратегий сверяются с исходниками
  nfqws v72.13, пресеты — со схемой §9.
- Размер: 155 файлов, 158 КБ без сжатия; в архиве gzip около 21 КБ, xz около 17 КБ.

## 9. Лицензии источников
