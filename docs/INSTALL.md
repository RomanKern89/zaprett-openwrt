# Установка zaprett на роутер с OpenWrt

**Русский** | [English](INSTALL.en.md)

zaprett ставится из готового **бандла** — архива `zaprett-<версия>-<OpenWrt>-<архитектура>.tar.gz`.
Внутри: пакеты (`feed/`), подписанный список пакетов, открытый ключ (`keys/`) и установщик `install.sh`.

Подходит для:

| OpenWrt | Менеджер пакетов | Какой бандл брать |
|---|---|---|
| 25.12.x | apk | `zaprett-…-25.12-<архитектура>.tar.gz` |
| 24.10.x | opkg | `zaprett-…-24.10-<архитектура>.tar.gz` |

Другие версии OpenWrt (23.05 и старше, snapshot) не поддерживаются.

---

## 1. Что понадобится

- роутер с OpenWrt 24.10 или 25.12 и **доступом в интернет** — зависимости (`ucode`, `nftables`,
  `kmod-nft-queue`, `luci-base` и др.) скачиваются из официальных репозиториев OpenWrt;
- не меньше **2 МБ** свободного места во flash: сами пакеты zaprett занимают 0,6–0,8 МБ (с nfqws2 — до 1,7 МБ),
  плюс зависимости, которых ещё нет в прошивке (например `kmod-nft-queue`). Проверить: `df -h /overlay`
  или LuCI → Система → Программное обеспечение (свободное место показано вверху страницы);
- доступ к роутеру: SSH (рекомендуется) или только веб-интерфейс LuCI — см. раздел 4.

## 2. Узнайте версию OpenWrt и архитектуру

**Через SSH:**

```sh
cat /etc/openwrt_release          # DISTRIB_RELEASE — версия, DISTRIB_ARCH — архитектура
cat /etc/apk/arch                 # OpenWrt 25.12: архитектура пакетов
opkg print-architecture           # OpenWrt 24.10: строка с наибольшим числом, например "arch mipsel_24kc 10"
```

**Через LuCI:** Система → Программное обеспечение → кнопка настройки репозиториев (apk в 25.12, opkg в 24.10).
В адресах репозиториев есть часть `…/packages/<архитектура>/…` — это и есть нужная архитектура
(например `aarch64_cortex-a53`, `mipsel_24kc`, `x86_64`). Версия прошивки — на странице Состояние → Обзор.

Примеры: роутеры на MediaTek Filogic (Xiaomi AX3000T и др.) — `aarch64_cortex-a53`;
роутеры на MediaTek MT7621 — `mipsel_24kc`; виртуальная машина x86 — `x86_64`.

Скачайте бандл **именно для своей версии OpenWrt и архитектуры**. Установщик проверяет это сам
и откажется ставить неподходящий бандл.

Не поддерживаются: ARMv4/v5 (`arm926ej-s`, `fa526`, `xscale`), `loongarch64`, `mips64el`, `powerpc64` и `riscv64`.

## 3. Установка через SSH (OpenWrt 25.12 и 24.10 — одинаково)

1. Скопируйте бандл на роутер в `/tmp` (это оперативная память, после перезагрузки файл исчезнет).
   С Windows 10/11 или Linux/macOS в терминале:

   ```sh
   scp -O zaprett-1.1.0-r1-25.12-aarch64_cortex-a53.tar.gz root@192.168.1.1:/tmp/
   ```

   Ключ `-O` нужен, потому что на OpenWrt нет sftp-сервера. Вместо `scp` можно использовать WinSCP
   (протокол **SCP**).
2. Зайдите на роутер: `ssh root@192.168.1.1`.
3. Распакуйте и запустите установщик:

   ```sh
   cd /tmp
   tar -xzf zaprett-1.1.0-r1-25.12-aarch64_cortex-a53.tar.gz
   cd zaprett-1.1.0-r1-25.12-aarch64_cortex-a53
   sh install.sh
   ```

   Установщик:
   - проверит, что бандл подходит к версии OpenWrt и архитектуре роутера, и что файлы бандла не повреждены;
   - добавит открытый ключ zaprett (`/etc/apk/keys/zaprett.pem` или `/etc/opkg/keys/<отпечаток>`);
   - обновит списки пакетов OpenWrt (`apk update` / `opkg update`);
   - поставит `zaprett`, `zaprett-nfqws`, `luci-app-zaprett` и `luci-i18n-zaprett-ru` из фида бандла —
     пакетный менеджер сам проверит подпись фида ключом zaprett;
   - напишет, какой адрес открыть в браузере.
4. Откройте в браузере адрес, который напечатал установщик, например
   `http://192.168.1.1/cgi-bin/luci/admin/services/zaprett` (LuCI → **Службы → zaprett**).
   Если пункта меню нет — выйдите из LuCI и войдите снова.

Дополнительный движок **nfqws2** (zapret2, Lua-стратегии) ставится ключом: `sh install.sh --with-nfqws2`.

Если на роутере не OpenWrt той версии, для которой бандл, установщик остановится. Ключ `--force`
разрешает продолжить при несовпадении версии OpenWrt (например, на 25.12-snapshot) или при смене ключа zaprett,
но так можно получить нерабочую систему пакетов. Неподходящую архитектуру или менеджер пакетов `--force` не
пропускает. Все ключи установщика — `sh install.sh --help`.

## 4. Установка только через веб-интерфейс

### OpenWrt 24.10 (opkg)

LuCI умеет ставить загруженные файлы `.ipk`.

1. Распакуйте бандл на компьютере (7-Zip, WinRAR или `tar -xzf`). Пакеты лежат в папке `feed/`.
2. LuCI → Система → Программное обеспечение → **«Обновить списки…»** (нужно для зависимостей).
3. Там же → **«Загрузить пакет…»** и установите файлы **строго по порядку**:
   1. `zaprett-nfqws_72.13-r1_<архитектура>.ipk`
   2. `zaprett_<версия>_all.ipk`
   3. `luci-app-zaprett_<версия>_all.ipk`
   4. `luci-i18n-zaprett-ru_<версия>_all.ipk`
4. Выйдите из LuCI, войдите снова и откройте **Службы → zaprett**.

При таком способе подпись фида не проверяется (opkg не проверяет подпись у загруженных вручную файлов) —
берите бандл только из официального релиза.

### OpenWrt 25.12 (apk)

Загрузка пакета через LuCI на 25.12 выполняет `apk add` **без** `--allow-untrusted` (проверено по исходнику
`luci-app-package-manager` 25.12.5), поэтому неподписанный отдельный файл пакета так поставить нельзя,
а добавить ключ zaprett из LuCI невозможно. Без SSH-клиента используйте терминал в браузере:

1. LuCI → Система → Программное обеспечение → «Обновить списки…», найдите и установите **`luci-app-ttyd`**.
2. Откройте **Службы → Терминал**, войдите как `root`.
3. Скачайте бандл прямо на роутер (если релиз доступен по прямой ссылке) и выполните шаги 3–4 из раздела 3:

   ```sh
   cd /tmp
   uclient-fetch -O zaprett.tar.gz "<ссылка на бандл из релиза>"
   tar -xzf zaprett.tar.gz && cd zaprett-*/ && sh install.sh
   ```

   Если прямой ссылки нет, скопируйте бандл на роутер через WinSCP (раздел 3, шаг 1).

## 5. Как проверить, что всё установлено

```sh
apk info -e zaprett zaprett-nfqws luci-app-zaprett luci-i18n-zaprett-ru     # 25.12: печатает имена установленных
opkg status zaprett | grep Status                                             # 24.10: "install ok installed"
ls -l /usr/libexec/zaprett/nfqws
```

В LuCI открывается **Службы → zaprett**. Страницы zaprett показываются на языке LuCI (System → System →
Language and Style, параметр Language), при значении «auto» — на языке браузера. Меню самого LuCI переводит отдельный пакет
`luci-i18n-base-ru`.

## 6. Обновление

### Из нового бандла

Скачайте новый бандл и выполните `sh install.sh` из него — так же, как при установке. Установленные пакеты
zaprett обновятся, настройки сохранятся.

### Штатно, через онлайн-фид (`--feed`)

Если при установке добавить ключ `--feed`, фид zaprett останется подключённым постоянно, и дальше zaprett
обновляется обычными командами пакетного менеджера — как пакеты самой OpenWrt:

```sh
sh install.sh --feed                    # установить из бандла и подключить онлайн-фид
                                        # (можно и позже: повторный запуск с --feed ничего не ломает)
sh install.sh --feed-url https://…      # то же, но с другим адресом фида (например, зеркало)
```

Фид — это сайт `https://romankern89.github.io/zaprett-openwrt/<версия OpenWrt>/<архитектура>/` с теми же
подписанными индексами, что в бандле. Подключается он так:

| OpenWrt | Куда записывается | Строка |
|---|---|---|
| 25.12 (apk) | `/etc/apk/repositories.d/zaprett.list` | `https://romankern89.github.io/zaprett-openwrt/25.12/<arch>/packages.adb` |
| 24.10 (opkg) | строка в `/etc/opkg/customfeeds.conf` | `src/gz zaprett https://romankern89.github.io/zaprett-openwrt/24.10/<arch>` |

Ключ zaprett ставится тот же, что при обычной установке, поэтому пакетный менеджер принимает только индекс,
подписанный ключом zaprett: подменённый или повреждённый фид он отвергнет.

Обновление после этого:

```sh
# OpenWrt 25.12
apk update && apk upgrade
# OpenWrt 24.10
opkg update && opkg upgrade zaprett zaprett-nfqws luci-app-zaprett luci-i18n-zaprett-ru
```

(Через LuCI: Система → Программное обеспечение → «Обновить списки…», затем вкладка «Обновления».)

**Если сайт фида недоступен** (нет интернета, github.io не открывается): на 24.10 `opkg update` только
сообщит об ошибке загрузки. На 25.12 apk строже — пока фид недоступен, `apk add` и `apk upgrade` **любых**
пакетов останавливаются с «Not continuing due to stale/unavailable repositories». Выход: подождать, временно
убрать файл `/etc/apk/repositories.d/zaprett.list` или добавить к команде ключ `--force-missing-repositories`,
который предлагает сам apk. Установщик из бандла это учитывает: на время установки он отключает онлайн-фид и
ставит пакеты только из бандла, а затем возвращает строку фида.

Отключить онлайн-фид: `sh install.sh --uninstall` (удаляет и пакеты), либо вручную удалить файл
`/etc/apk/repositories.d/zaprett.list` (25.12) или строку `src/gz zaprett …` из `/etc/opkg/customfeeds.conf` (24.10).

Без `--feed` установщик фид не подключает: фид бандла живёт только на время установки, и `apk upgrade` /
`opkg upgrade` zaprett не обновляют — только новый бандл.

## 7. Удаление

```sh
cd /tmp/zaprett-*/            # любой распакованный бандл для вашей версии OpenWrt
sh install.sh --uninstall           # удалить пакеты, настройки оставить
sh install.sh --uninstall --purge   # удалить пакеты, /etc/config/zaprett, /etc/zaprett и ключ zaprett
```

`--uninstall` также отключает онлайн-фид zaprett, если он был подключён ключом `--feed`.

Без бандла:

```sh
# OpenWrt 25.12
apk del luci-i18n-zaprett-ru luci-app-zaprett zaprett zaprett-nfqws zaprett-nfqws2
rm -f /etc/apk/keys/zaprett.pem /etc/apk/repositories.d/zaprett.list
# OpenWrt 24.10
opkg remove luci-i18n-zaprett-ru luci-app-zaprett zaprett zaprett-nfqws2 zaprett-nfqws
sed -i '/^src\/gz zaprett /d' /etc/opkg/customfeeds.conf
```

(`zaprett-nfqws2` указывайте, только если ставили его; `opkg`/`apk` сообщат об отсутствующем пакете.)
Через LuCI: Система → Программное обеспечение → вкладка «Установленные» → удалить те же пакеты в том же порядке.

## 8. После обновления прошивки (sysupgrade)

Прошивка OpenWrt не содержит пакетов zaprett, поэтому после `sysupgrade` или обновления через LuCI
(«Прошить новую прошивку…») **пакеты zaprett пропадают**. Настройки (`/etc/config/zaprett`, `/etc/zaprett`)
сохраняются, если при прошивке было отмечено «Сохранить настройки».

Что делать после обновления:

1. Если OpenWrt обновился в пределах ветки (например 25.12.4 → 25.12.5) — снова скопируйте на роутер тот же
   бандл и выполните `sh install.sh`. Настройки подхватятся.
2. Если ветка сменилась (24.10 → 25.12) — возьмите бандл для новой ветки: у 25.12 другой менеджер пакетов.
3. Ключ zaprett тоже может пропасть — установщик добавит его заново.
4. Если был подключён онлайн-фид (`--feed`), запустите установщик снова с `--feed`: строка фида будет
   записана заново, даже если прошивка её не сохранила.

**Обновление через Attended Sysupgrade** (LuCI «Обновление прошивки», `owut`) собирает образ на сервере
OpenWrt только из официальных пакетов. Пакетов zaprett там нет — перед таким обновлением удалите zaprett
(`sh install.sh --uninstall`, настройки останутся) или используйте обычный `sysupgrade`, а после обновления
поставьте zaprett заново.

## 9. Частые ошибки

| Сообщение установщика | Что делать |
|---|---|
| «бандл собран для архитектуры X, а роутер — Y» | Скачайте бандл для архитектуры Y (раздел 2). |
| «бандл для apk (OpenWrt 25.12), а на роутере opkg» | Нужен бандл `…-24.10-…` (или наоборот). |
| «apk add / opkg install завершился с ошибкой», в выводе нет пакета `kmod-nft-queue`, `ucode` и т.п. | На роутере нет интернета или не обновлены списки. Проверьте `ping downloads.openwrt.org`, повторите. |
| «UNTRUSTED signature» / «подпись фида не прошла проверку» | Бандл повреждён или подменён. Скачайте заново из официального релиза. |
| «на роутере уже есть другой ключ» | Бандл подписан не тем ключом, что стоял раньше. Если вы уверены в источнике — `sh install.sh --force`. |
| `apk update`: «wget: exited with error 8» / `opkg update`: «Failed to download … zaprett-openwrt …» | Онлайн-фид недоступен (нет интернета или сайт фида ещё не опубликован). Остальные репозитории это не затрагивает; пакеты zaprett остаются установленными. |
| «No space left on device» | Мало места во flash: удалите ненужные пакеты или используйте extroot. |
